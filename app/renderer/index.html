What Is an ICMP Flood?

🛎️ SIMPLE ANALOGY

The College Office Doorbell: Imagine repeatedly ringing a college office's doorbell hundreds of times every minute. The staff becomes occupied answering the door, so genuine students waiting outside struggle to receive help.

Simple Definition

An ICMP Flood is a denial-of-service attack where a target receives excessive ICMP Echo Requests (pings), consuming processing capacity and disrupting legitimate traffic.

ICMP Diagnostic error reporting protocol.
Echo Request Ping diagnostic: "Are you alive?"
Echo Reply Target response: "Yes, I am here."
PPS (Rate) Packets Per Second: triggers CPU interrupts.
CPU Usage Processor capacity spent handling pings.
Denial of Service Making a system unreachable for users.
Sender (Attacker)
══[Avalanche of Pings]══>
Target Server
══[100% CPU Locked]══>
Service Disruption

👀 What You Will Observe:

  • Packet Rate: PPS surges from ~0 to 35,000+ packets/sec.
  • Target CPU: Processor spikes toward container core limit.
  • Server Health: Switches from HEALTHY to CRITICAL (DoS).
🔒 Safety Notice: Runs exclusively against the isolated local Docker test container. No traffic leaves your machine.
