ICMP Ping Request & Reply Mechanics Chapter 3

1. Normal Ping vs ICMP Flood Comparison

2. ICMP Message Code Architecture

ICMP Type 8: Echo Request

Sent by the diagnostic client. Contains identifier, sequence number, and optional data payload. Triggers an obligatory response from the receiver.

ICMP Type 0: Echo Reply

Sent by the target server. Must mirror the exact identifier and data payload of the incoming Echo Request, forcing the server to construct packets in RAM.

Why ICMP Floods are Deadly to Small Servers

Because ICMP is connectionless, the attacker does not need to complete a handshake or maintain memory state. The attacker simply fires raw packets at wire speed. The target, however, must expend CPU cycles decoding each packet, computing checksums, and building reply packets.

2. Network Layer vs Application Layer Exhaustion

Volumetric (Layer 3 & 4)

Goal is brute force pipe saturation. Measured in Gigabits per second (Gbps) or Millions of Packets per second (Mpps). Requires high attacker bandwidth or botnet amplification.

Application (Layer 7)

Goal is exhausting backend computation (e.g. database search queries or SSL handshakes). Requires very low bandwidth from attacker but brings down multi-core databases.

When Local iptables is Sufficient

When attacks are low-to-moderate volume (e.g. single-source DoS in our lab) and network bandwidth is not completely saturated.

When Cloud Scrubbing is Mandatory

When the volume of attack traffic exceeds the physical bandwidth of the host's network cable (e.g. 50 Gbps flood targeting a 1 Gbps port).

1. The Doorbell (ICMP)

A flood attack is like ringing a doorbell thousands of times so the staff cannot help real visitors.

2. The Bouncer (Firewall)

A firewall stops unauthorized packets at the door, but alone cannot stop millions of packets flooding the street.

3. The Turnstile (Rate Limiting)

Rate limiting lets 1 person through at a time, keeping the room calm without shutting down the facility.

4. The Highway Bypass (Scrubbing)

Upstream scrubbing centers divert massive multi-gigabit traffic away before narrow residential streets choke.

5. The Golden Cybersecurity Rule

Encryption protects Confidentiality; Defensive Architecture protects Availability. A complete cybersecurity engineer always protects both!
